# Fleet PDF (`pdf_export.py`)

Read before changing `pdf_export.py`, the print dialog (`/print`) or `data/quickref/`.

- `fleet_pdf(fleets, designs_by_fleet, options) -> bytes`, with `PrintOptions` mirroring the
  print dialog (PLAN 10.3). One fleet is a fleet pack; two are a battle pack (both rosters,
  sheets and trackers, an orders chart each, one shared quick reference).
  `battle_pack_error()` rejects two rulesets; `/print` GET is the dialog, POST returns the PDF.
- `draw_diagram()` renders the **same `ssd_layout` primitives** the screen does, so screen =
  paper. Two fpdf2 traps: `circle()` takes the centre and the radius (its docstring says
  bounding box) and a filled path needs colour strings, not tuples. Arc rings are sampled into
  polylines in `ssd_layout`, so both renderers draw the identical points.
- Fonts are the bundled IBM Plex TTFs (`static/fonts/`); no system font is used.
  `PrintOptions.style` is `mono` (default, ink-saving black and white) or `color` (blue dossier
  accents), selected independently of the screen theme. Both keep black-on-white SSDs. Shared
  page furniture, wrapping/repeating roster tables, bounded tracker cards and two-column
  references use the same print-first layout on A4 and Letter. Rulebook text and SSD primitives
  stay unchanged. Running headers abbreviate long fleet names; body identities wrap in full.
  The ruleset is on every page.
- Record sheets and the orders plot follow the **Full Thrust Light** ship record sheets (Master,
  2026-10-22: at least six ships a page): landscape pages of cards with the class up a left
  strip, an ID tab, name and MASS/points along the top and the SSD over a hull silhouette (filled
  in colour, outline in mono). Ships go largest first; each page takes the grid in `GRIDS` (4x3,
  4x2, 3x2) that holds the most of the next cards with every SSD at `MIN_SCALE` or more, spanning
  slots (`SPANS`) for a ship no single slot holds. One scale per page, so every box on a sheet is
  the same size; `draw_diagram(view=)` crops to the drawn extent (`_bounds`). The orders plot
  (ship rows, Start V, orders + V per turn) always gets its own landscape pages, never under the
  cards (Master).
- The tracker (`_tracker_rows`) and the quick reference read what a ship carries: its own
  loadout, else the design's default. Empty bays print nothing, a light wing is 8 fighters and 4
  endurance (PC p.75), a magazine shows its loaded salvos; with damage printed, lost fighters,
  spent salvos and used one-shots are struck out. Gunboats anywhere add the `gunboats` key.
- Quick reference: `data/quickref/<ruleset>.json`, generated by `tools/extract_quickref.py`
  (its traps are in `tools/CLAUDE.md`); **never paraphrase it by hand.** `pdf_export` adds
  play-rule keys to the present set (`no_ftl`, `starbase`, `troop_hold`, `dummy_bogeys`,
  `armour_regen`, `stealth_hull`).
- An inline binary response (the PDF) opens from a blob in a new tab in the web build.
- `tests/test_pdf_export.py` reads the generated pages back with pymupdf. Render pages to PNG
  for a visual check when the layout changes.
