Full Thrust Fleet Manager

A local fleet manager for Full Thrust. Design ships, build fleets to a points limit, track campaign damage and print a fleet PDF for the table. No login, no server, no cloud: download it and everything runs on your own PC, or play entirely in your browser.

Not affiliated with Ground Zero Games.

▶ Play online, no download vDEV

Run the full app right in your browser. It works like the desktop version, and your library is saved in this browser, so closing the tab or refreshing is safe. That storage belongs to this device and browser only, so export a backup file to keep your designs and fleets safe or to move them elsewhere. The first load fetches a runtime, so give it a few seconds.

🪟 Windows vDEV

No Python install needed. Works fully offline.

  1. Unzip it anywhere (your Desktop or Documents, for example).
  2. Run FullThrustFleetManager.exe inside the unzipped folder.
  3. It opens in your browser automatically. A tray icon lets you quit it later.

The exe is signed (“Deltrex”), but with a self-signed certificate rather than a paid one, so SmartScreen may still warn the first time. Click “More info”, then “Run anyway”.

🐧 Linux vDEV

No Python install needed. Works fully offline.

  1. Extract it: tar -xzf FullThrustFleetManager-*-linux-x64.tar.gz
  2. Make it executable: chmod +x FullThrustFleetManager
  3. Run it: ./FullThrustFleetManager, which opens in your browser.

Or from a file manager: right-click, Properties, allow executing, then double-click.

Linux builds are occasional rather than one per release, so this link points at the newest release that has one rather than at the latest release.

What it does

  • Design ships to the Fleet Book or Full Thrust 2nd edition rules, with live MASS and NPV, an arc picker and a rules check. Break the rules on purpose if you like; the design is then marked non-conforming.
  • Build fleets to a points limit, in squadrons, from your own designs or the 141 ship classes of the books, with a tournament check that lists every violation.
  • Field the alien races: Kra’Vak, Sa’Vasku and Phalon, each with its own systems, record sheet icons, rules check and quick reference, alongside the human fleets.
  • Track a campaign: damage marked by clicking the ship diagram, crew factors, repairs and replenishment, and a fleet log.
  • Print a fleet pack or a two-fleet battle pack: roster, record sheets, orders chart, ordnance tracker and a quick reference.
  • Read the rulebooks in the app, with every page reference in the UI linking straight into them. Seven books ship: the four core GZG ones, plus Cross Dimensions and Project Continuum with its errata.
